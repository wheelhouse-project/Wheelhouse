# Overlay stack requirements (place 2: areas S3 and U4)

Bead: `wh-full-refactor.4.1` (stage A of place 2 of the epic `wh-full-refactor`).
Extracted on 2026-11-12 from the code at dev `77b253cc`. The code of both areas is the same at dev `4d04d813`.

This document covers two areas of `docs/design/refactor-area-map.md`.
Area S3 is the bare-number holds and the spoken-click holds of `SpeechProcessor`.
Area U4 is the overlay walk, the snapshots and click N of `UIActionHandler` in the Input process.

Each row states one rule as an input at a boundary of the class and the output that leaves the class.
For S3 the inputs are the word events and utterance ends that the STT path gives to `SpeechProcessor`.
For U4 the inputs are the six messages from Logic: `start_overlay_walk`, `show_numbered_overlay`,
`pin_snapshot`, `unpin_snapshot`, `refresh_overlay_snapshot` and `click_snapshot_item`.
The outputs are messages and replies on the queues, typed words, and calls on a fake operating system seam.

## Status values

The status values and their meaning are those of `docs/design/overlay-requirements.md`, section "Status values":
CONFIRMED, OPEN, NOT_REQUIRED and NOT_WANTED.
Under the refactor rule (David, 2026-11-06), today's shipped behavior is the requirement.
A row with the source "today's shipped behavior (refactor rule, David 2026-11-06)" is CONFIRMED for that reason.
A row with no test gives its reason in the Tests or Note column.
The reason "waits for the injected clock" means that the test needs a real wait of more than 1 second.

## Rows that `docs/design/overlay-requirements.md` already has

This document does not repeat those rows. It cites them by their identifiers.

- S3: CK-47 ("click" and a number word, digit or homophone is a numbered click) and CK-48 (the grid is open).
  BN-11 and BN-12 cite them. No other CK, LC, RW or AO row covers a bare number or a spoken-click hold.
- U4: LC-11, LC-14, LC-15 and LC-25 state how Logic reads the walk and pin replies.
  CK-3 states that Logic sends `click_snapshot_item`. CK-20 to CK-25 state how Logic reacts to a refusal.
  None of them states what `UIActionHandler` puts in a reply, so the IW rows state the Input side.
