Get started

I would start with the default speech recognition. It runs on your own computer, and it does not need an account. You can try the other options later.

Allow about
10–20 minutesfor installation.

The download of the speech model and the software that it needs takes most of that time.

Full installation guide →

What you need

  • A Windows PC. Windows 10 or 11, 64-bit. The installer checks whether Wheelhouse supports your Windows version.
  • At least 8 GB of RAM. I recommend 16 GB. Setup won’t proceed below 8 GB with the offline speech engines. With cloud speech recognition, about 6 GB is enough.
  • 10 GB of free disk space. The program and its speech model use this space.
  • A microphone. The built-in microphone of your laptop can be enough. You can connect a microphone after installation.
  • An internet connection for setup. The default speech recognition works offline afterward.

The recommended number of CPU cores is four or more. A slower processor can take longer to turn speech into text.

1

Download Wheelhouse.

This step gets the Windows installer from the project’s GitHub release page. You do not need a GitHub account.

Download Wheelhouse-Setup.exe ↗
2

Open the file and follow setup.

The installer checks your computer and asks which options you want. Keep the default local speech recognition if you want speech to stay on your computer.

AI text rewriting is optional. The setup wizard offers a Google cloud option. You can skip it. The full installation guide explains the separate command-line setup for local AI.

If your computer needs Microsoft’s Visual C++ runtime, Windows can ask an administrator to approve its installation.

Windows shows a security warning.

The installer is digitally signed. Its publisher must be David Chesley Hite III. That is me. Windows SmartScreen can still warn about a download that it does not see often.

Open More info and check the publisher name. Then choose Run anyway. If the publisher name does not match, stop. Then get in touch.

Read the full explanation of installation warnings.

3

Try your first few words.

Start Wheelhouse from the Start menu if setup did not open it. It listens in its default mode when it starts. Open Notepad. Put the cursor in the empty document.

Try these one at a time. Leave a brief pause between the commands:

  1. Say hello worldYour words appear.
  2. Say new lineThe cursor moves to the next line.
  3. Say undoThat new line is removed.
  4. Say select allYour text is selected.

If those worked, you are ready to use Wheelhouse. If they did not work, the setup checks help you find where the failure is.

Pause and resume listening

You can pause listening with the floating button or the tray icon. Use the same button or icon to switch it back on. Wheelhouse also has voice commands and listening modes for hands-free use. The guide explains when each one applies.
